# 繪世 PC 桌面遷移預覽

本目錄是繪世 PC 的 Electron 桌面遷移預覽工作區，並非正式發行版。

- **目前文件：** 產品主說明請見 [PC 端 README](../README.md)；功能範圍與驗收狀態請見 [PC 端規劃](../docs/PC_PLAN.md) 和 [手機功能對照](../docs/MOBILE_PARITY.md)。
- **發行與更新：** 目前沒有公開安裝程式或正式發行連結，且自動更新尚未啟用。上游專案的發行附件不是繪世安裝程式。
- **獨立資料：** Windows 使用者資料位於 `%APPDATA%\NAI-WorldPainter-PC\`，設定檔為 `worldpainter-desktop.json`。程式不會自動掃描或共用上游應用程式的資料目錄；舊 Flutter 工作區須透過應用程式內的明確匯入流程遷移。

- **本專案儲存庫：** [NAI-WorldPainter-PC](https://github.com/liyi3068238601-oss/NAI-WorldPainter-PC)。
