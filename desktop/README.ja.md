# NAI WorldPainter PC — デスクトップ移行プレビュー

このディレクトリは、NAI WorldPainter PC の Electron デスクトップ移行プレビューです。正式リリースではありません。

- **現在の製品説明：** [PC プロジェクト README](../README.md) と、機能範囲・受け入れ状況を記載した [PC 計画](../docs/PC_PLAN.md) を参照してください。
- **公開・更新：** 公開インストーラーや正式な配布リンクはありません。自動更新は無効です。上流プロジェクトの配布物は WorldPainter のインストーラーではありません。
- **独立したデータ領域：** Windows のユーザーデータは `%APPDATA%\NAI-WorldPainter-PC\`、設定ファイルは `worldpainter-desktop.json` に保存されます。上流アプリのデータを自動で検索・共有しません。旧 Flutter ワークスペースはアプリ内の明示的なインポート機能でのみ移行してください。
- **ソースとライセンス：** デスクトップ実装は [Langbai NovelAI Studio の上流ソース](https://github.com/2786886095/novelai-image-desktop)を基にしています。MIT ライセンスと著作権表示を [LICENSE](./LICENSE) に保持しています。[上流ソース説明](./docs/upstream-reference/README.md)も参照してください。上流のリリース履歴は出典記録のみです。
- **本プロジェクト：** [NAI-WorldPainter-PC](https://github.com/liyi3068238601-oss/NAI-WorldPainter-PC)。
