# NAI WorldPainter PC — 데스크톱 마이그레이션 프리뷰

이 디렉터리는 NAI WorldPainter PC의 Electron 데스크톱 마이그레이션 프리뷰 작업 공간입니다. 정식 릴리스가 아닙니다.

- **현재 제품 문서:** 제품 개요는 [PC 프로젝트 README](../README.md), 범위와 검수 상태는 [PC 계획](../docs/PC_PLAN.md)을 확인하세요.
- **배포와 업데이트:** 공개 설치 파일이나 정식 배포 링크가 없습니다. 자동 업데이트는 비활성화되어 있습니다. 업스트림 프로젝트의 릴리스 파일은 WorldPainter 설치 파일이 아닙니다.
- **독립 데이터:** Windows 사용자 데이터는 `%APPDATA%\NAI-WorldPainter-PC\`에, 설정 파일은 `worldpainter-desktop.json`에 저장됩니다. 업스트림 앱의 데이터 폴더를 자동으로 검색하거나 공유하지 않습니다. 기존 Flutter 작업 공간은 앱의 명시적 가져오기 기능으로만 이전할 수 있습니다.
- **소스와 라이선스:** 데스크톱 구현은 [Langbai NovelAI Studio 업스트림 소스](https://github.com/2786886095/novelai-image-desktop)를 기반으로 합니다. MIT 라이선스와 저작권 표시는 [LICENSE](./LICENSE)에 보존되어 있습니다. [업스트림 출처 안내](./docs/upstream-reference/README.md)를 참조하세요. 업스트림 릴리스 기록은 출처 자료일 뿐입니다.
