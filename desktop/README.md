# 绘世 PC 桌面迁移预览

本目录是绘世 PC 的 Electron 桌面迁移预览工作区，不是正式发行版。

- **当前文档：** 产品主说明见 [PC 端 README](../README.md)，功能范围与验收状态见 [PC 端规划](../docs/PC_PLAN.md) 和 [手机功能对照](../docs/MOBILE_PARITY.md)。
- **发行与更新：** 当前没有公开安装包或正式发行链接，自动更新未启用。不要将上游项目的发行附件当作绘世安装包。
- **独立数据：** Windows 用户数据位于 `%APPDATA%\NAI-WorldPainter-PC\`，设置文件为 `worldpainter-desktop.json`。不会自动扫描或共用上游应用的数据目录；旧 Flutter 工作区须通过应用内的显式导入流程迁移。
- **来源与许可：** 桌面实现基于 [Langbai NovelAI Studio 上游源码](https://github.com/2786886095/novelai-image-desktop)，按 MIT 许可保留来源署名，见本目录 [LICENSE](./LICENSE) 和 [上游来源说明](./docs/upstream-reference/README.md)。上游历史发行记录仅作为来源档案保存。
- **本项目仓库：** [NAI-WorldPainter-PC](https://github.com/liyi3068238601-oss/NAI-WorldPainter-PC)。
