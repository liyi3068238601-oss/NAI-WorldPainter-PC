PC 独立实现允许的修复：手机画面橡皮只擦图像笔迹overlay，但其composeBase请求/保存代码会直接清原图alpha，存在显示/输出不一致与损图风险。新模块在独立overlay中擦除后再与原图合成，确保原图像素不丢失；测试专门覆盖此差异。PC候选进入历史等额外差异由主报告逐项列明。

自动化建议包括分数坐标贴边、完全越界与透明图、处理尺寸变化不改worldRect、蒙版顺序与8px对齐、扩展欧氏半径、羽化内外单调、请求框触边、1×1图、预乘alpha白底无暗边、负坐标扩画布、同批候选替换、批次失败保留、后续请求不回灌结果、独立蒙版撤销和换图重置。单测不替代Windows Electron实际GUI。
