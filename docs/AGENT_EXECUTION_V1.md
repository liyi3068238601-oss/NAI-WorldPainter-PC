# 绘世内置 Agent：任务执行与 Skill 第一版

日期：2026-10-15。实现范围为 `desktop/` 的当前 Pi Agent 主链；不把旧 Flutter 或 Tavern 测试结果计为本批结果。

## 使用变化

- 助手资源栏以 Skill 替换世界书，预设、角色和记忆保留。支持新增、编辑、删除自定义 Skill、全局启停、会话选择和关键词自动匹配；内置绘世生图、改图、查词三个工作流。旧世界书数据保留在磁盘，但不进入当前 Pi 助手上下文。
- 每轮只发送适用 Skill 的简短目录，通过 `read_skill` 按需读取正文；Skill 不能扩大工具或付费权限。用户选择的预设继续通过原设置生效。新增技能最多 64 项，会话目录最多 24 项，新正文最多 12,000 字符；旧超限资料保留原文，拒绝加载半截工作流。
- 生成/改图请求要求模型执行到实际结果或具体阻塞；对陌生角色、作品、标签和画师主动查本地标签，必要且联网已启用时查公开网页。不会把整个私有提示词作为搜索请求，也不会把未查证内容称为已验证。
- 启动引导左侧图片使用手机端 `assets/style_presets/style_001.jpg` 原始文件，与用户截图一致；按完整比例显示，沿用绘世配色。

## 根因与修复

| 问题 | 现在的行为 |
| --- | --- |
| 多轮后工具回执被拼进普通助手文本，容易诱导模型打印调用代码 | 历史重建为配对的原生工具调用/工具结果消息，包含状态和不确定性，结果先脱敏。后续仍提供完整工具 schema。 |
| 模型只打印函数调用 | 检测已挂载工具的调用格式，最多追加一次协议纠正；真实调用仍走校验、确认和执行。不解析执行函数文本，纠正失败明确报告未执行。 |
| 确认模式第一项付费操作后不能继续不同步骤 | 相同工具、相同参数每轮只执行一次；不同请求步骤分别确认，可生成后放大。失败或结果不确定后，本轮其余付费操作停止。 |
| 上传图只有视觉字节，没有可用于工具的 ID | 为当前会话可用图片提供有界附件清单；视觉关闭也能按 ID 编辑，文件缺失明确标记。不给模型本地路径。 |
| 编辑确认缺少当前默认参数，等待确认时设置可变 | 确认卡显示有效模型、提示词、尺寸、强度和参考参数摘要；绑定设置/账户指纹，确认后改变则拒绝执行。来源和蒙版使用附件 ID。 |
| Director 字段错配、未知操作悄悄转成背景移除 | 上色字段规范化、兼容旧别名但冲突拒绝；只接受六种已实现操作。局部重绘不再暴露后端不支持的参考/角色参数，也不再静默丢弃。 |
| 保存的是流式中间承诺，空回复被称为完成 | 保存最终答复；拒绝、空结果、长度截断和协议纠正失败明确显示状态；已完成图片与回执保留。工具快照发送前先排空流式队列，避免界面短暂重复同一句话。 |
| 多步只统计最后一次模型用量 | 汇总本轮全部模型调用，保留后续回复失败前已报告的用量。 |

确认模式每轮最多 12 次工具调用，全自动最多 32 次；全自动只改变逐次确认方式，不取消重复付费和失败保护。提示词转换、优化/编辑和视觉反推同样标记为可能收费。原转换服务内部的模板验收重试机制仍保留，本批未重写。

## 验证与边界

自动测试、构建、包校验及 Windows UI 结果见 [验证记录](evidence/agent-execution-v1/verification.json)。本地 HTTP 模拟 Provider 验证多轮原生工具调用与结果配对、拒绝、失败、函数文本纠正、Skill 延迟读取及工具返回脱敏；它检验应用执行链，不代表真实模型必然遵循提示。

最终回归为 445 个测试文件、4,105 项通过、2 项跳过、0 项失败；类型检查、前端/主进程构建及 Windows x64 解包构建通过。包内欢迎图与手机端原图字节一致，关键 Agent 主进程模块与本地编译结果一致。Windows 本地模拟完成三轮对话、十次模型协议请求，包含重启后继续执行、确认写入提示词、函数文本纠正及用量累计。最终包再次检查了流式重复问题；欢迎页与预设截图来自同一前端的前一个打包候选，截图阶段在验证记录中逐项标明。

Windows 验收使用独立 `.tmp/agent-native-v1`（开发候选）和 `.tmp/agent-native-final`（打包候选）合成目录。复现用 [本地模型夹具](../scripts/agent-native-fixture.cjs)，只监听 `127.0.0.1`，实际工具操作限读取状态与应用合成提示词。无真实模型、NovelAI 或其他付费调用。

剩余边界：真实模型的连续生图/编辑与主动查词成功率尚待指定账号和预算下验收；新图准备 ID 会阻止重复消费，但模型重新准备同样内容不是跨 ID 去重。编辑快照不对附件 ID 对应文件计算内容 hash。Skill 为应用内声明式工作流，不执行外部脚本。完整手机功能矩阵及 M4 未闭合项继续见 [迁移报告](M4_ELECTRON_MIGRATION.md)。
