# 提示词知识与提案应用批次

日期：2026-10-14。承接 `60a84d3`，继续 M4 内置助手。本批没有增加生图渠道，没有请求真实 LLM、图片模型或收费服务。

## 用户入口

- **AI 助手 → 模型与偏好 → 提示词知识**：选择 V4.5/V5，当前会话保留选择，新会话沿用最近设置，旧会话缺省按 V4.5 恢复。该设置只决定助手使用的知识，不改变生成模型。
- V5 Agent 注册 `read_prompting_reference`，按需读取构思、写法、权重、多角色、文字和质量词六个主题；V4.5 直接注入基础摘要。工具只读固定本地内容，结果带知识版本、资料修订和官方 URL，不读取任意文件或网络。
- 完整回复包含明确 JSON 或带目标标签的代码块时，出现 **查看提示词提案**。弹窗展示各词框修改前后，允许选择部分字段并填写变更原因；取消不改草稿。
- 应用后在同一会话保存版本、时间、原因和选中字段的前后记录。重启可以展开查看，不重复执行；旧回复没有草稿版本时仅供查看。

## 写入与兼容约束

发送前冻结知识版本、草稿 fingerprint 和重绘模式。只有最终完整 assistant 回复可以作为文本提案，流式片段、失败/取消轮次和工具调用 JSON 不会自动执行。结构化写词工具仍要求前置读取及应用层确认；同轮经确认的工具写入会推进本轮 fingerprint，外部草稿编辑不会推进它。

提案准备和确认时分别核对当前会话、回复内容、草稿版本、关闭/维护/生成/编码状态。所有目标在一次同步写入前统一校验，选中字段和应用记录进入同一 SQLite CAS 工作区快照。保存失败时保留内存中的匹配记录与词框并明确提示，允许通过工作区保存重试，不能再次应用同一提案。

文本 JSON 格式为 `positive`、`negative`、`characters`（最多六个对象，每个有 `positive`/`negative`）和可选 `reason`；空字符串不清空词框，省略字段不修改。重绘会话把全局正负字段明确映射为局部重绘目标。也支持带正向/负向/角色编号标签的 Markdown 代码块。纯 JSON 或单个 JSON 围栏可解析；嵌在任意散文中的 JSON 不猜测提取。字段类型错误、重复键/目标、多份 JSON、过深或超长内容明确拒绝。

限额：输入 200,000 字符、JSON 32 层、每目标 24,000 字符、合计 96,000 字符、变更原因 1,000 字符。当前角色上限保持六槽。原始权重、空白和换行保留，Markdown 围栏分隔换行除外。会话分支复制历史时分配新 turn ID，避免跨会话重复 ID 使持久化校验失败；历史应用记录仍保留。

## 参考实现与移植差异

核对了手机端版本选择、动态工具注册、文本解析器和本地浪白的预览/过期拦截。手机端文本解析器有源码和测试，但当前生产代码没有引用；修正了矩阵旧说法。手机提示词包带 GPLv3 文本，本批没有搬运其中的社区语料，采用独立整理的官方摘要。详细路径、固定版本、手机文件 SHA-256 和官方来源见 [来源记录](PROMPTING_SOURCES.md)。

本批实现的是基础指南与受控读取，不等于完整迁移手机社区技能资料的深度。手机工具参数为 `ideation|writing`，PC 内部采用包含这两项的六主题 `topic` 枚举；二者不宣称字节兼容。官方模型页和文字页对 V5 文字长度的单位表述不一致，摘要保留差异，不把该数值当硬限制。

全量 Flutter 测试 **357 项通过**，Dart 静态分析无问题，Windows/Web Release 构建及 Windows 存储/凭据探针通过。新增测试覆盖六主题工具读取、非法主题/取消、解析歧义/重复/限额、会话版本隔离、回复/审批期间编辑、SQLite 重开、保存失败后恢复、分支 ID、逐字段应用及旧记录。Widget 截图覆盖桌面差异确认、应用记录和紧凑窗口只读提示，主控已检查画面。

最终日志、截图、源码及构建哈希见 [validation.json](evidence/prompting/validation.json) 和 [SHA256SUMS.txt](evidence/prompting/SHA256SUMS.txt)。测试入口为 `test/assistant/prompting_*`、`test/assistant/prompt_proposal_test.dart` 和 `test/prompting_ui_test.dart`。集成测试输出 `.tmp/prompting-native-fixture.json`；复现原生检查可用现有 `scripts/tag-agent-qa-mock.py --prepare --fixture .tmp/prompting-native-fixture.json --data-dir .tmp/<新的隔离目录>`（仅使用其通用 SQLite 初始化能力，不启动服务），再用 `WORLDPAINTER_DATA_DIR` 指向该目录启动 Release 程序。

Web 构建仍有既有的 CupertinoIcons 字体族提示；本批实际使用的 Material 图标已在 Windows 成品确认可见。浏览器人工交互及真实模型效果未在本批验收。
