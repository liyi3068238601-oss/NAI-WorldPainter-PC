## U05：手动选择 V4.5 不再被误判为迁移

**修复前复现**：全新隔离配置，默认 V5→手动选 V4.5 Full，立即弹出升级提醒。[005 修复前](evidence/uiux-phase2-20261020/screenshots/005-before-manual-v45-unwanted-notice.png)。

**根因**：旧逻辑只在实时模型不是 V5 时展示并记录提醒。新配置使用 V5 时没有记录“已评估”，因此主动切回旧模型也被当作旧配置迁移。

**修改**：将提醒生命周期提取到 `use-v5-migration-notice.ts`，显式等待 `bootDone && settings`。首次恢复为 V5 的配置也标记已处理；首次恢复为旧模型时仍展示一次提醒。保留旧提醒键、首次展示即记录以防强制关闭反复弹出、截图模式抑制。模型和已保存提示词均不被这一 hook 修改。

**真实 GUI 对照**：

| 场景 | 结果 | 截图 |
|---|---|---|
| 新配置 V5→主动 V4.5 | 没有提醒，显示所选 V4.5 | [060](evidence/uiux-phase2-20261020/screenshots/060-u05-after-manual-v45-no-notice.png) |
| 保存上述选择后完整重启 | 没有提醒，模型仍为 V4.5 | [061](evidence/uiux-phase2-20261020/screenshots/061-cold-start.png) |
| 合成旧 V4.5 设置，没有 Chromium 提醒记录 | 仍显示首次提醒 | [062](evidence/uiux-phase2-20261020/screenshots/062-cold-start.png) |
| 点击保持当前模型后完整重启 | 不重复提醒，模型仍为 V4.5 | [064](evidence/uiux-phase2-20261020/screenshots/064-cold-start.png) |

旧配置场景仅复制本次新建隔离配置的合成 JSON 至另一个空 profile，没有读取真实配置，也没有调用内部接口替代点击。9 项 hook 生命周期测试覆盖异步恢复、主动选旧模型并重启、旧配置提醒保持、关闭/强制退出后的去重、两个旧键与截图模式。这些测试执行实际 hook 的状态与 effect，不是真实 React DOM；GUI 证据单独报告。

## 独立原型与待确认范围

原型 A 展示“参数在前、账户展开”的近似特征，不是现状产品的完整复制；B 展示“正负提示词在前、账户收起”的提案。布局比较复用真实 `Button`、`SelectMenu`、`CommittedNumberInput`、`EffortControl`、`ResolutionPicker`，并沿用产品 CSS、暖金深色和白蓝浅色。没有导入 `App`、业务 store、产品 preload 或 `naiDesktop`。

可交互：A/B、账户展开收起、主题、模型/尺寸/Seed、正负提示词与画师串、7 个页面切换及页面内存草稿；模拟生成确认/取消/结果/元数据/回填；Agent 模拟确认；重绘蒙版状态示意。漫画、素材、创作为入口和草稿示意，未实现其业务。图片预览只通过 FileReader 读取用户自行选择的文件至内存。本次未选择真实图片。

所有生成与 Agent 都在内存中模拟，没有费用、队列、模型请求或真实文件写入。原型草稿只在当前打开期间保留，刷新清除；这不代表产品最终草稿策略。HTML 的 CSP 禁止联网，预览包装器也拒绝非 file/data/blob 资源。没有使用真实账户、图库或工作区。系统字体回退避免携带外部字体依赖。

原型在独立 Electron 预览中实际验证 1280×720、1440×900、125% DPI、深浅主题及关键交互。未把它当成 Windows 原生产品或浏览器全兼容验收。核心布局提案尚未应用，等待用户比较后选择；不需为了评审原型启动产品。
