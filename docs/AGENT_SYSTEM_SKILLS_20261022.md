# PC 助手基础指令、预设与 Skill 重构

日期：2026-10-22。开发分支：`feat/agent-r4-refactor`。

## 本轮交付

- 基础指令仅常驻应用操作、权限、版本校验、回执、图片观察和消息队列边界。默认助手预设只保留创作方向；不再重复注入旧 amendment 或 V5 根 Skill 全文。
- 七个内置 Skill 按任务读取：画面构思与分镜、NovelAI 分版本写词、多人物构图与坐标、工作台写入与生图、连续改图与局部重绘、标签与设定核验、创作记忆。既有五个 Skill ID 保留。目录可使用同一创作最近四条用户消息匹配后续请求，不读取无关工作台。
- 三个可选内置助手预设正文保持原样。默认预设仅升级旧原厂 revision 1 且正文和记录哈希均匹配的内容；保留原版本历史、用户编辑、绑定、停用选择及排队消息快照。自定义 Skill 保留。
- 模型仅使用当前 PC 原生接口。历史兼容映射与历史消息保留，但不作为本轮工具或规则。

## 坐标接口与校验

`write_workbench_prompts` 继续使用完整 `characterPrompts` 数组和 `expectedDraftRevision`。新增可选的 `characterLayoutIntent`：

- `planned`：本次参与生成的角色均需 `useCoords=true`，且 `x/y` 为有限的 `[0,1]` 数值。已有合法的全坐标调用可省略此意图，保持兼容。
- `free`：明确采用生图模型自由布局，本次参与生成的角色均需 `useCoords=false`。新增自由布局或从坐标布局切换时必须明确传入。
- 旧混合布局的纯文字修改、安全删除和纯重排可保留，新增或移动不得造成模式混用。停用角色保留其布局；无法证明身份对应时拒绝猜测。
- 主进程与 renderer 的 CAS 入口共享校验。版本冲突优先返回，不自动重读重试；无效布局不提交部分修改。

坐标是位置锚点，不是身体边框或关节。接触动作允许重叠与中心点；程序验证完整性和模式一致性，不保证模型精确遵守构图、肢体动作或角色关系。

## 知识与参考

原始手机端 JSON、Skill 与参考文件均不改动。PC 现有内置知识库保留 12,738 条、8,882,911 bytes。

检索改为标题/关键词相关性排序、英文词界与短语匹配、中文匹配、规范化内容去重、命中位置摘要和缓存索引。最多返回五条，单条内容最多 900 字符、总内容最多 2,400 字符；注入的完整 JSON 另有 12,000 字符上限。

`read_prompting_reference` 仍仅接受 `reference: ideation | writing`，按需返回 PC 适配内容。移除移动端执行规则、过时工具指导和“所有动作只能放主提示词”等冲突结论，同时保留具体创作技法与原始来源。已配置参考版本与实际生图模型明确区分。
