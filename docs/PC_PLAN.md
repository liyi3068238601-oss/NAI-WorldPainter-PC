# 绘世 PC 端规划

日期：2026-10-11。版本：0.1。状态：规划初稿，应用开发未开始。

## 已确定的目标

用户要求建立自己的 GitHub 仓库，全部工作位于 `E:\NAI-WorldPainter\PC端`，并明确首版同时支持 NovelAI 官方和兼容网关。仓库为 `liyi3068238601-oss/NAI-WorldPainter-PC`，当前设为私有。

首个交付目标暂定 Windows 10/11 x64 独立桌面客户端。具体最低系统版本在打包验证时确定；macOS、Linux、移动端同步留作后续扩展。桌面工作区使用鼠标、键盘、文件拖入、多栏编辑和大图预览。

## 首版的创作流程

1. 配置官方 Persistent API Token，或兼容网关的地址、协议类型和 API Key；明确当前选用的渠道和模型。
2. 编写正负提示词、角色和参考图，或从本地图片导入所选参数。保留未保存草稿。
3. 生成前展示实际参数、能力限制、批量次数和费用信息；未知费用标为未知。
4. 提交任务后继续编辑其他草稿；结果始终归属提交时的任务快照。
5. 结果写入本地文件和图库，按单图记录实际 Seed、尺寸、渠道与参数来源。
6. 从所选图片复用参数、进入图生图或局部重绘，派生结果另存并保留来源关系。
7. 用提示词助手提出修改，审阅差异后应用；关闭并重新打开应用仍能找回已保存结果。

## PC 工作台布局

左侧为导航与项目/图库；中央为画布、选中图和结果缩略图；右侧为提示词、模型参数、角色与参考图。助手可切换为侧面板，队列放在底部可展开区域。窄窗口可收起左右面板，保留画布和主要生成操作。

拖入图片先选择用途：查看参数、导入提示词、图生图输入、蒙版源图或参考图。切换渠道时展示不兼容字段，用户决定调整或放弃切换，不静默删除输入。批量操作明确目标数量，失败后仍保留已经生成成功的图片。

M1 原型验证 1280×720 与 1920×1080 两种窗口、100%/150%/200% 缩放、键盘焦点、长提示词、空图库和错误状态。测试结果与截图一起保存；原型截图不能冒充可运行产品。

## 核心数据约定

| 对象 | 必须解决的问题 |
| --- | --- |
| ProviderProfile | 渠道身份、规范化 origin、协议类型、凭据引用和能力版本分离 |
| Draft | 用户编辑内容有独立 ID 与 revision，助手返回不能覆盖后续编辑 |
| GenerationSpec | 提交时冻结提示词、角色、参考资产、Seed 意图和目标操作 |
| GenerationPlan | 记录校验后的实际参数、适配器版本和费用来源；不能暗中改参数 |
| Job | 持久化状态、请求标识、尝试次数和错误；不确定是否扣费时不自动重试 |
| ImageAsset | SHA-256、文件路径、实际尺寸与 Seed、来源任务和父图片；未知字段明确为空 |

图库索引与原图文件分开保存，原图默认不覆盖。用暂存文件加原子改名和数据库事务提交；文件成功但索引失败时保留待恢复记录。删除采用可恢复操作，并检查派生图与项目引用。外部图片导入默认复制到受管目录；未经明确操作不移动源文件。

运行数据根目录由应用明确管理，开发数据在本仓库被忽略的 `data/` 下。分发后的应用数据目录在 M1 定案，支持独立于安装目录并明确备份范围。图片、数据库、凭据不能默认进入 Git。

## 技术路线建议

暂推荐 Electron + React + TypeScript + SQLite，以独立 PC 工作台为目标实现。手机端和 Web 参考项目用于提取经过验证的功能契约、交互模式和故障案例；不整仓搬运。Flutter 与 Tauri 的比较、选型验证和成本见 [技术路线](ARCHITECTURE.md)。

技术栈尚未锁定。M1 在桌面窗口、凭据存储、SQLite 打包、大图浏览和文件保存的最小验证通过后，更新选型决定。若手机端代码获得明确复用许可且保持 Dart 共用成为优先目标，应重新比较 Flutter 的总成本。

## 首版验收清单

- 官方和至少一个已声明的网关分别验证支持的模型、操作、请求与响应；第三方失效不能被展示为官方故障。
- 分别测试 401、429、超时、断网、损坏响应、取消，以及生成成功但本地落盘失败；不确定结果不自动重复收费。
- A/B 图片快速切换、生成期间更改草稿、切换渠道、助手迟到响应，都不串图、不串凭据、不覆盖新草稿。
- 随机 Seed 保存真实返回值，缺失时说明未知；复用参数不承诺服务端输出逐像素一致。
- 模拟进程退出后，已完成结果可重开，运行中请求标记为结果待确认，不假装仍在生成或直接重发。
- 中文与空格路径、同名文件、只读目录、磁盘不足、图库缺失文件、数据库迁移及恢复有明确行为。
- 安装包在独立 Windows 环境打开，能保存/重开图片、使用 SQLite 和凭据存储；原生依赖随包验证。
- 自动化契约测试、UI/文件流程测试、人工视觉检查、真实付费服务测试分别留下证据；没有执行的项目明确标注。
