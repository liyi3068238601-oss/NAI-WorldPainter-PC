## 动画和流畅感：观察与限度

已操作侧栏、设置标签、主题、角色折叠和图片缩放，保存了内置浏览器 CDP screencast 的 **10 张采样帧及原始时间戳**。侧栏从图标宽度向完整宽度过渡时，内容区随之调整；源代码 `main/page.js` 的 240px 完整导航与短过渡和实际布局相符。

采样有工具调用间隔和确认机制，不是连续无损录屏，更不能用相邻帧间隔计算应用 FPS。36/37 张低复杂度 PNG 的操作未出现阻塞操作的错误，不能据此宣称大图、真实生成和大图库“稳定 60 FPS”。绘世原型仍须独立测量输入响应和帧时间。

值得借鉴的是状态连续和反馈位置稳定：导航不清草稿，生成键不跟随长表单消失，预览旁能直接执行下一步。绘世不需要复制整套主题定制项或所有动效。初始动效规范定为：悬停/按下 100–140ms、展开/折叠 180–220ms、主题 180ms；只作为原型起点，响应应可中断，减少动画时取消位移与缩放。

## 界面方案决定

采用 **左导航 + 中央画布/结果 + 右提示词/参数 + 固定生成区**。顶部保留任务标签；中央底部为当前任务结果条；图库是独立模块，不把所有历史长期挤进工作台。

绘世导航覆盖创作、图库/素材、图像工具、助手、漫画、Pixiv、设置。队列作为全局任务入口，布局不能删去任何手机功能。首版不加入参考项目独有的新功能。

以 1440px 视口为原型基准：导航 208px/折叠 64px，右参数面板约 400px，中间弹性占满；低于 1360px 默认折叠导航，保留展开选择。1280×720 下保持生成按钮可见。分界尺寸是设计初值，后续用实际绘世原型及高 DPI 修正。

主视觉保持绘世近黑背景 `#0A0A0C`、面板 `#1C1C21`、暖金 `#F5D57A`；浅色继续白底蓝色。参考界面的品牌、蓝灰色、内置人物图片不作为产品素材。

## 技术路线决定与复核条件

选择 Flutter Windows 作为下一步实际实施路线：手机已有渠道、Agent、漫画和数据模型，先全量移植的成本主要落在业务完整性。此次体验中的多栏布局、独立滚动、角色网格、蒙版与短过渡没有显示必须依赖 React 的能力，因此不因参考 UI 技术栈而全面改写 Dart 业务。

PC 表现层独立开发，手机业务按模块复用和适配；原生能力集中适配 Windows。不要整体复制手机页面，也不默认引入 Next.js/Flask 双运行时。

Electron + React + TypeScript 是明确的后备路线：浪白 MIT 项目已含 NAI 请求、元数据回填与漫画队列，不能按全从零估算；但其数据模型不等同手机端，现有 Electron `sandbox: false` 配置也不能直接照搬。两份参考代码持续可作协议、算法和测试依据，复制前记录许可与来源。

M1 先做 Flutter 的最小完整路径：多栏原型、长提示词输入、蒙版、后台任务中切草稿、Windows SQLite 重开、凭据往返、中文路径保存、本地超分独立后端。只有遇到可复现且成本不可接受的桌面阻碍，才对同一失败用例实现 Electron 对照；不同时维护两个完整客户端。手机根许可证缺失仍需在代码导入前解决，但不取消功能范围。
