# 提示词素材管理批次

日期：2026-10-13。用户本轮要求暂不增加生图渠道；GPT/Nano 仍保留在全量移植范围，本批推进 M4 的离线素材管理。此次不调用生图、LLM、WD 或其他真实远端接口。

## 已接入的工作流

- 左侧“提示词素材”入口与创作参数区快捷入口，包含风格收藏、画师串和灵感胶囊。沿用绘世深浅主题、侧栏和响应式布局。
- 风格支持新增、编辑、删除、全文搜索、分类、保存当前正负提示词以及自选预览图。追加时分别进入当前正向与负向草稿，逐字保留已有内容、换行和权重语法。删除收藏不删除图像文件。
- 画师支持新增、编辑、删除、名称/tag 搜索、多分组、空组维护、改名与删除分组。按名称、更新时间、Danbooru 热度排序；本地使用次数单独记录，不冒充远端热度。多选权重范围 0.1–8.0，默认 1 输出原始 tag，其他权重使用 `weight::tag::`，保留输入数值精度。组合可复制或追加到正向草稿。
- 画师 JSON 复制沿用手机端 version 12 的字段结构；导出 ID 在这次导出中为唯一整数，未携带 PC 默认权重与本地使用次数，因此不是 PC 全库备份。没有新增导入入口或声称已运行手机端导入。
- 灵感胶囊支持中英搜索、分类/子类、正负向切换、多选预览和分别追加；切换正负向时清空所选项，避免把旧选择插错词框。载入 4,121 条 MIT 上游词库，14 类、112 子类、119 条负向。来源和 MIT 全文可在搜索框右侧信息按钮查看。
- 自建风格、预览图引用、画师、分组与默认权重进入工作区自动保存；旧工作区缺少 `promptLibrary` 时创建空库。存在但损坏的库拒绝读取，不悄悄清空。素材编辑不改变生成模型、渠道、尺寸或 Seed。资产审计会扫描风格预览引用，保护仍被收藏使用的图像。

## 未完成范围

- 手机 24 个风格预设、137 条画师内置记录及预览资源尚缺可核实的独立资源许可，本批未复制；可管理用户自己的收藏。这两项不宣称完整 parity。
- 手机当前胶囊扩展文件标注 6,747 条合并前原始项，基础文件另有 463 个显式项；本批使用固定 MIT 上游去重 taxonomy，尚未完成手机词库逐项差异与来源核对，不能按条目数量宣称完全一致。
- 助手输入插入、LLM 会话/多模态/工具、记忆、在线标签查询、WD-Tagger 仍未迁移；风格本批追加到创作草稿。
- 画师选择与临时滑块组合是面板内临时状态；库条目和默认权重持久化。关闭素材页后可重新选择，不能把临时选择描述为持久化组合预设。
- 手机 v22 数据导入、大图库性能、多个实例同时资产维护、安装包与全量 M6 验收不在本批完成范围。
