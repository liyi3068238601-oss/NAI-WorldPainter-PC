# Agent 预设入口统一

按用户本次确认，保留“当前创作 → 资源 → 预设”的列表，移除输入框下方的助手预设选择器。此次决定替代此前把助手预设放在输入工具栏的布局安排。

- 资源列表直接展示 R4 助手预设库，选择标记、启用状态和实际发送配置使用同一个会话绑定；内置名称、导入预设、R4 自建预设和正文详情均保留。
- “启用”和“设为新会话默认”集中到资源预设列表头部。普通选择只改变当前会话，默认值仍需明确设置。
- 导入预设时，在同一 SQL 事务内保存正文和当前会话绑定；保留启用状态，不改变新会话默认，完成后刷新资源列表的实际状态。
- 运行时的预设标识、修订、摘要和 system 正文使用同一份消息快照，切换预设不会改变已入队消息。

`npm run typecheck`、`npm run build` 和 Windows x64 目录打包通过。包内 12 个关键文件与当前构建逐字节一致，包含实际 store、runtime、资源上下文 helper 及 Agent renderer。

实际窗口已检查资源列表选择、启用切换和进程重启后的原会话绑定，输入区无重复控件；800×720 renderer 视口模拟未见输入与发送重叠。合成占位运行会话使聊天切换按钮禁用，因此本轮没有将原生聊天切换列为通过项。“设为新会话默认”保留并检查可见性，未在原生测试中点击。
