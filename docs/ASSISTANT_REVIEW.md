# PC 小助手与内置 Agent 批次

日期：2026-10-13。延续手机端全量迁移范围，本批实现助手主体与第一组工具；按用户安排，未增加生图渠道。不存在真实账号、真实远端模型或付费生成验收。

## 已接入

- 侧栏 AI 助手页面：会话新建、切换、重命名、确认删除、复制回复；编辑/重试创建分支，原会话不被覆盖。SQLite 保存会话、草稿、附图引用、连接、工具记录及偏好，重启把未完成任务标为中断，不自动恢复执行。全部清空已有控制器能力，界面入口尚未接入。
- 多个 OpenAI 兼容 Chat Completions 连接，独立绑定对话/识图模型；流式与非流式模式、精确模型 ID、自定义偏好和最近 1–20 个完整轮次。Windows Key 使用凭据管理器，按连接 ID 和 API 根地址隔离；浏览器只保存在会话内存。编辑地址后需要为新地址另存 Key，旧地址凭据不会发送到新地址。
- 最多 4 张、每张 10 MiB 附图，先通过已有资产验证/存储，再由单独绑定的识图模型生成描述。描述保存并参与后续上下文，后续轮次不重复上传像素。导入期间禁止发送、切会话和资产维护；导入纳入关窗等待屏障。
- 同一注册表产生工具 schema 并负责分派；只执行结构化 `tool_calls`，不会从普通回答、代码块或图片文字中抽取指令执行。工具参数先通过本地 schema 校验，再准备、确认、执行、按 `tool_call_id` 回传并继续模型轮次。
- 最多 16 轮、64 次调用、每个回复最多 16 个调用，连续工具失败上限 3 次。网络请求不自动重试。用户拒绝结束本轮，缺少确认回调默认拒绝；停止/关窗不会默认同意。

## 工具与执行边界

| 工具 | 本批行为 |
| --- | --- |
| `read_current_prompts` | 读取当前正负词、重绘词、角色和草稿版本。 |
| `write_prompt` | 先读取，再显示修改前后并确认；支持追加/替换及角色目标，审批后重查草稿版本，用户期间改过草稿则拒绝迟到写入。 |
| `remove_character` / `clear_characters` | 先读取、显示目标并确认；按当前版本更新角色槽。 |
| `ask_user` | 显示 2–6 个选项和自由输入；回答后继续；关闭或停止结束本轮，没有默认答案。 |
| `search_prompt_materials` | 检索本地风格、画师和 MIT 离线胶囊；不宣称联网 Danbooru 检索。 |
| `read_gallery` | 读取最近 20 张真实图库图片 ID/元数据；不上传图片像素。 |
| `save_image` | 仅通过图库 ID 选择真实受管图片，确认目标图片后进入原有系统另存流程，不接受任意路径。 |
| `generate_image` | 只在接入实际生成 runtime 时注册；沿用当前已有渠道，确认模型/尺寸/Seed/正负词/张数后执行文生图；本批 1–8 张，返回真实入库 ID。图生图与重绘仍从工作台操作。 |

`save_image` 已开启的系统保存窗口不能由 Agent 取消信号撤回。停止时记录“操作可能已经生效”，不自动重试；已经完成的草稿编辑/图片保留。生成失败或部分完成按工具错误回传，不能把已有部分图片当成整批成功。

## 避免“说了但没有调用”

普通对话使用 `auto`，可合法零调用，并显示“本轮未调用工具”。勾选“本轮必须调用工具”后首轮发送 `required`：首轮无结构化调用或整轮没有任何工具成功，则明确失败。这个选项保证至少一次工具成功，并不证明模型已满足全部语义意图。

“测试工具调用”只暴露 `diagnostic_echo`，要求模型回显本轮随机值；必须完成请求、结构化调用、本地执行、结果回传和最终回答才显示通过。服务拒绝 `tools`/`tool_choice`、忽略 required、返回截断响应等情况不会静默降级为普通聊天成功。该按钮会调用用户选择的对话服务，可能按该服务规则计费；本次开发只用合成服务。

SSE 按调用 index 累积 ID/名称/参数，要求完整 finish reason 与结束事件；允许合法 usage 尾事件。JSON/SSE 都限制在 1 MiB；普通回复和思考协议字段分开处理。`reasoning_content` 只作为不透明协议字段在同端点/模型的后续请求中回放，切换端点或模型时移除，不把它作为可执行指令或展示给用户。
