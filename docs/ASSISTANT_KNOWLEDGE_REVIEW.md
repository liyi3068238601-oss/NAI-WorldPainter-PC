# 小助手记忆与素材批次

日期：2026-10-14。承接 `412d7add3ba38e835e6ef248a899b18d13a1df4f` 的助手主体，继续 M4；本批未增加生图渠道，没有请求真实模型或付费生成服务。

## 可用入口

- **AI 助手 → 记忆**：8 类记忆、4 类来源的查看/筛选，手工增改、候选采纳/编辑后采纳/拒绝，触发词冲突的替换/合并/并存。显示命中次数、最近命中时间、创建时间和替代历史；管理搜索不计命中。
- **长期未命中**：列出创建超过 90 天、从未命中的有效正式记忆。新建记忆、待审核候选和已替代历史不进入此列表。先选记录，再预览实际删除集合，最后确认；没有自动清理。
- **批量选择/删除**：若删除替代链的最终记录，关联旧历史也会被删除，避免恢复出过时记忆。预览完整列出所有受影响记录；取消无变化。单删旧历史不删除后继记录。
- **聊天输入框旁的素材按钮**：搜索并插入已有本地风格、画师和离线胶囊，保留已有草稿。正负风格词分别标注，画师保留默认权重。插入不自动发送、不改创作词框。
- **模型与偏好 → 新增/编辑连接 → 读取此连接的模型列表**：显式查询当前地址的 `/models`，搜索并选择完整模型 ID；支持取消、失败后手动重试。新增连接只用当前输入的 Key；编辑已有连接可复用同一 ID/地址下的凭据。未保存 Key 不写入凭据库或工作区，改地址不会借用旧地址 Key。
- **会话操作 → 清空全部会话**：再次确认后清空聊天与聊天草稿，保留记忆、收藏和图片文件。

## Agent 与存储

`get_memories` / `save_memory` 接入已有 schema、执行分派、工具时间线及多轮回传，沿用结构化 `tool_calls`。普通文本不能执行工具，连接诊断仍只暴露无副作用的 `diagnostic_echo`。

`save_memory` 只提交待审核候选，不需要再弹一次确认；它无权采纳、替换或删除已有记忆。相同触发词/内容/类别的候选去重。候选内容可供用户审核，但不会被 `get_memories` 返回；只有用户在记忆界面采纳后才生效。工具返回明确的 `pending_review` 和 `active: false`，不宣称已成为正式记忆。

`get_memories` 只查有效正式记录，最多 8 条，触发词和内容合计最多 12,000 字符；超预算记录整体跳过。支持关键词和中文整句内的触发词匹配。只有实际返回的记录增加命中数。结果会发给本轮配置的模型服务，作为可参考数据，不作为系统指令或操作授权；内容未联网核验。无默认全库注入。

记忆随现有 SQLite 工作区的 `assistant.memories` 节点保存，独立记忆 schema 为 1；旧助手快照缺少此节点时使用空库，节点损坏或未知 schema 不静默丢弃。数量上限 5,000，触发词 200 字符，内容 8,000 字符。修改先完整校验再更新；弹窗携带 revision，列表变化后拒绝过期决定。替代历史不可编辑，有效记录修改触发词仍能保持可重开的历史关系。保存失败沿用工作区错误提示和关闭保护。
