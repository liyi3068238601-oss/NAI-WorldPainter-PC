## 合同与文档

- `python -B validate_registry.py`：36 工具、239 个 JSON Schema fixtures、50 个执行语义案例通过；11 种 executionStatus 均有正反例，保留 3 个原始 R3 聚合反例及 8 个历史结构反例。
- 8 个合成参考授权上下文案例通过，覆盖用途改变不继承旧授权及明确重新 opt-in。它们不能证明真实用户事件或授权来源。
- 取消业务结果按四种 disposition 覆盖：requested 9 正/5 反，already_terminal 6 正/2 反，not_cancellable 3 正/5 反，not_found 1 正/1 反。
- `sync_tool_summaries.py --check`：36 工具的五类派生摘要均与 registry 一致。完整输入、结果 schema 使用 Draft 2020-12 校验。
- 内联 JavaScript 解析通过。主控复核了聚合校验、取消分支及精确参考授权判断；新合同与流程、提示词、UI 规范、验收矩阵交叉核对。没有把通过样例等同于真实 host。

## 下载的证据边界

最终控件为可见原生 `<a download>`。示例 href 的 MIME 是 image/svg+xml，文件名有 .svg；从可见链接提取的 SVG 内容保存在 source/download-link-payload.svg 并作 XML 解析。这是链接内容证据，不是浏览器已保存文件的证据。

内置浏览器原来的下载事件等待、以及最终原生链接的 `downloadMedia` 均超时，未返回下载文件路径。未绕开浏览器权限，也未声称原图保存、hash 一致或真实种子获取已经通过。外部浏览器落盘、真实文件导入/下载和原生 Windows 行为留给实施验收。

## 中间观察与修正

- 一次用途撤销点击后立即读取未看到变化；以同一回执明确入口复测成功，后续独立清源撤销也成功。没有为未定位的单次点击引入补丁。
- 曾在任务完成并退出活动列表后查找运行中计数，检查时点错误；首次点击“继续队列”后已即时观察到次数 1，终态从活动列表退出属正常行为。
- 排队取消主卡原只写未产生结果，与规范不够一致；已补确切未发送标签并在刷新恢复后观察到新标签。
- 早期页面仍持旧 R4 存储键时跨文件更新重载过一次；正式恢复检查在 Final 独立存储键下重做，未把跨版本页面测试算通过。
