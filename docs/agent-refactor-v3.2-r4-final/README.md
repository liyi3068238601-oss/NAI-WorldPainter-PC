## 打开与体验

打开 [交互原型](prototype-v3.2-r4.html)，从顶部 **原型演示** 菜单开始。无账号、无网络模型、无付费请求；固定示例回复不是实际语言理解能力。

1. **重启后的继续队列**：选择“准备恢复场景：未发送排队”，可再准备“可能已提交”，随后“模拟重启并恢复”。前者等待手动继续，后者只能核实，不会自动重发；混有待核实任务时先处理它再继续队列。任务卡与全局队列显示同一状态和模拟提交次数。
2. **任务取消**：取消排队任务观察零提交；也可用“准备取消场景：已返回 1 张”观察部分结果保留；对“可能已提交”任务请求取消，再选择确认取消、不支持、未知或迟到成功回执。作品按实际结果保留。取消图像任务与停止文字回复相互独立。
3. **聊天修改参考**：菜单“填入：改为仅讨论”仅修改用途；“填入：改为仅讨论后生成”会在修改成功后打开预览。也可用原型支持的明确标题修改用途、参与生成或移除源图。回执可撤销，后续又改输入时旧撤销显示冲突。
4. **预览变化**：选源图后发送“移除改图源”，在回复结束前打开生成预览。清源生效后旧确认失效，重新预览才可提交；此前入队任务仍保留原输入。
5. **查看图片**：菜单插入同批横竖多图，点图或按 Enter/Space 打开查看器，切范围、前后切图、适应/放大、查看模拟种子、下载示例 SVG。

重载演示仅用当前标签页 sessionStorage 保存本地任务快照，不能证明真实应用磁盘持久化、崩溃恢复、远端取消或扣费正确。关闭标签页后不保证保留；非队列创作编辑也不是完整存档功能；源图/参考无法恢复时会阻断继续。核实为失败后保留暂停，不自动推进。实际测试与限制见 [VERIFICATION.md](VERIFICATION.md)。

## 保留的 R4 基础规则与本轮收尾

- 36 项工具摘要从 registry 生成；保留完整 23 组目录与单次请求最多 10 组的区别，校验器检查摘要漂移。
- 原消息不变 → 同回合授权 CAS 修改派生有效输入 → 准备、批准、持久入队绑定执行快照；三个边界统一。
- 聚合先判断待核实，再判断正常在途，最后判断终态证据；未来派发阻断与当前任务状态独立。
- 依赖输入在入队前变化拒绝旧预览；入队后修改不会改写原任务；无关创作变更不误伤预览。
- 验收矩阵补同回合改输入后生成，并对五类图片工具逐一参数化，产品验收仍为待执行。
- UI 演示暂停按任务持有；异步刷新保留参考区状态与焦点，不抢输入框，输入新文字不会使图片用途修改误报冲突；查看器边界有可用键盘落点。
- 改图源跨讨论、入队和完成保留，不自动换成新结果；只有明确移除或换图改变该绑定。
- 启停助手预设保留选择；新会话默认显式保存；发送配置、生成配置和自动点评配置不被后来的切换倒灌。
- 固定提案不因更换讨论中的当前方案而失效；真实图片输入变化仍要求重新预览。
- 参考参与授权绑定确切目标、附件修订与用途；模型的 true 不是授权，换用途不沿用旧用途授权。

可补充体验：准备两条未发送演示任务，加入一次普通生成，逐条取消演示任务；仅最后一个演示暂停原因解除后普通任务开始。发送用途修改后，在回复到达前展开参考区并聚焦用途控件，观察展开和焦点保留。
正式实现仍需真实 host + fake provider 的副作用、事务、并发和崩溃注入验证，再做模型协议及真实服务验收。本轮不将 HTML 演示或 schema 通过当作这些层级的证据。

## 可直接输入的精确演示语句

- `把参考图“橱窗暖光参考”改为仅讨论`
- `把参考图“橱窗暖光参考”改为色彩，参与生成`
- `把参考图“橱窗暖光参考”改为仅讨论，然后生成`
- `移除改图源` 或 `移除改图源，然后生成`（先明确选择源图）

这些语句用于固定场景演示，未接入真实模型，也不代表能理解任意自然语言。
