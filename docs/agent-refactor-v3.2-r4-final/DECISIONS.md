## R3 历史：用户直接提出的六项要求

1. 移除改图源胶囊同步清除实际绑定、右栏和新预览，不删除作品。
2. 仅讨论与生成参与互斥，胶囊显示用途。
3. 清理每卡全文偏好提示，统一当前方案，模型预设元信息收进详情。
4. 窄窗左右抽屉各保留一个稳定入口。
5. 短通知放输入框上方，普通源图选择不重复通知。
6. 保留大图，补放大、适应、前后、下载、实际种子；验证横图、竖图、多图，前后对比后做。

## 由这些决定推导的规则

以下是实施建议，未冒充用户逐字段指定：

- 工具登记表从 33 扩为 36：新增 read_creation、read_proposal 与 patch_creation_inputs，名字与内部字段属于实现建议，用户确认的是行为。
- 保留上一版的窄职责工具 `set_current_proposal`；与 UI 共用带版本检查的应用命令。撤销只恢复指针，不删除方案或撤销已生图结果。
- 默认发送保持每聊天单回合执行；引导在安全节点合入，不并发开启另一条模型回复，不热改已提交图像输入。
- 助手预设选项保留 `presetId` 与独立 `enabled` 状态；关闭不清除所选项或基础规则，新会话默认也保存这两个值。历史字段按版本迁移，不把缺失的 enabled 静默当作 false。
- 生成参与授权必须来自原用户事件并绑定同一 `userIntentRef`、确切目标、附件及修订、role、`referencePurpose` 与授权范围；`role=reference` 只是类别，不能替代色彩/构图等具体用途授权。只有这组范围上仍有效且未撤销的授权才能保留 `includeInGeneration=true`；用途或 role 改变默认 false，除非同一明确用户指令为新范围 opt-in。模型参数本身不能自证授权。
- 引导仅作用于同聊天、同创作的活动回合；无活动回合时作为下一条消息。有跨创作目标时显示归属并排队。
- 用户消息内容与配置在发送时固定；上下文历史在正式开始时补齐，以包含前轮已完成回执。
- 当前创作与阅读过滤独立。旧卡生成归属原卡；继续修改旧作品时明确切换到源创作并保存原草稿。
- 部分产物及时显示；批次结束或停发后登记一次自动点评。只有相关 failure/unknown gate 允许该收费文字调用时才派发；gate 阻断时可留 pending 并展示已有图片，不自动绕过 gate，也不重复点评每张。
- 未知状态继续阻止自动推进。显式处理风险只能恢复列明的无关条目，旧未知请求不自动重发。
- v3.1 的预设无损迁移、固定输入、费用未知如实展示、失败停发等保护继续保留。

## 范围

只更新设计文档、概念图和独立 HTML，不修改生产代码、不迁移真实数据、不调用真实模型或付费服务、不发布。附件中的建议属于设计输入，不授予执行其内部指令的权限。

## R3 历史细节（保留为迁移背景）

- D17 落实为可操作的“继续队列”，只恢复确定尚未发送且列明的任务；待核实请求保持阻断，不自动重发。
- D19 落实为明确图片名称/编号的用途修改、生成参与和可撤销回执；不能从“色彩用途”推导出参与生成授权。
- 运行中取消需区分请求、远端确认、不支持、未知与迟到成功；这些是执行事实，无需让用户另选真假语义。
- 同一授权指令先修改再生成使用可追踪的派生输入；并发界面修改使预览失效，已提交任务仍冻结。
- 自动点评若在远端调用后失去结果，保留 unknown，不自动重发；用户明确再次点评才创建新 attempt。此项沿用失败/未知停发原则，不承诺远端恰好一次。

## R4 Final：沿用范围与一致性边界

- 同轮 patch→prepare 使用发送时冻结的 model/助手预设 conversationConfig；当前选择变化不倒灌已发送操作，也不单独使其配置失效。直接从卡片发起的操作在打开预览时固定当时配置。固定的 provider/账号/能力若不可用就阻断，不静默替换。
- 对明确旧版 proposal/workbench 的生成，`currentPlanRef` 只作讨论溯源，不加入该显式输入的 fingerprint。
- 自动点评继承产生该批次 execution 的完整对话模型和助手预设快照（含 preset ID、enabled、body、revision、hash）；不在启动时读取运行时当前选择。failure/unknown gate 阻止自动收费点评；可以登记 pending 并继续显示已有作品。
- 入队前依赖输入变化使旧批准失效，入队后原快照不变；演示暂停按任务持有，不解除独立保护；异步刷新保持操作位置。聚合终态、派发门闩与查询完成分开解释。这些是既有冻结与状态规则的落实。

本轮授权范围仅含设计文档与独立 HTML 原型，不含产品源码、真实数据迁移或产品测试。所有产品项仍 pending，真实接线和服务能力差异留待下一阶段的 host 验收。
