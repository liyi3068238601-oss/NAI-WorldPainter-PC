## 合同静态验证

主控独立执行 `python validate_registry.py`：**36 项工具、215 个 schema fixtures、15 个语义案例、8 个旧/新反例通过**。日志见 [schema-validation.log](schema-validation.log)，逐工具四类基础覆盖见 [COVERAGE.md](schema-fixtures/COVERAGE.md)。R3 registry 和工具 schemaVersion 为 2.0.0；R2 保留 1.0.0。

校验包括统一发现组映射、host 字段声明、五类共享提交上下文、前置失败分支、反推结果约束、输出计数/索引/种子/聚合状态，以及递归遍历和 completed 附件身份变异检查。pending output 不强制要求尚未存在的作品身份。静态 fixtures 不能证明真实 handler 拒绝输入时副作用为零。

主控读取并重跑 R2 的 8 个反例，全部复现原报告；旧预览竞态也在浏览器实际复现。原始记录位于 source。脚本解析、重复 HTML ID 与网络调用标识检查通过；没有将这些检查替代实际交互。

## 浏览器交互

| 流程 | 实际观察 | 证据/限制 |
| --- | --- | --- |
| 混合任务重载 | 未发送任务恢复为暂停/0 次；可能已发任务为待核实/1 次；继续入口禁用直至核实 | 实际点击模拟重启并刷新，非生产进程崩溃 |
| 未知任务核实 | 仍未知保持阻断；确认终态后恢复手动继续入口 | 本地选择回执，不是远端查询 |
| 继续队列 | 核实后点击“继续队列（1 项）”，原未发送任务开始并产出 2 张示意图 | 模拟计数只代表本地函数事件 |
| 取消排队 | 未提交任务取消，回执提交次数 0 | 不代表真实 worker CAS 已验收 |
| 运行中取消 | 先显示取消请求；不支持取消分支继续等待并保留 2 张结果 | 没有远端取消/退款验证 |
| 取消未知与迟到成功 | unknown 阻断；迟到成功仍保存 2 张图片 | 同一任务状态与聊天卡同步 |
| 部分结果后确认取消 | 固定“已返回 1 张”场景进入 partial，保留 1 张，不补生成第二张 | 本地确定性演示 |
| 聊天仅改参考 | 明确标题从参与生成改为仅讨论；勾选关闭且禁用，胶囊更新，不打开生成预览 | 固定语句解析，不是自然语言模型 |
| 聊天明确参与 | 色彩+明确参与后胶囊和勾选均为参与生成 | 未调用真实服务 |
| 同轮修改后生成 | 成功用途回执后打开新预览，讨论参考不进入生成 | 原消息与旧执行快照不回写 |
| 撤销与冲突 | 无后续变更时恢复原用途/参与；有新编辑时保留新值，冲突长驻回执 | 非数据库并发压力测试 |
| 旧预览竞态 | 清源回复生效后旧确认 disabled；警告明确，重新预览去掉旧源 | 确认处也有修订/指纹复查；host 原子性未实现 |
| 重新预览版本 | 保持原提案修订 1（存在修订 2），输入升修订，仍需手动确认 | 没有静默换成最新方案 |
| 同图资产/参考绑定 | 从参考入口打开原作品，显示“色彩 · 参与生成” | 不再读作品默认用途冒充绑定 |
| 查看器键盘/范围 | Enter 打开作品，Space 打开参考；范围 select 更新后焦点仍为 viewerScopeSelect | 未完成所有平台辅助技术验收 |
| 横竖多图 | 800×900 下竖图适应框 client/scroll 高均 556；横图均 253；放大产生滚动，切图恢复适应 | 本地 SVG 横竖 3 图，非所有真实分辨率组合 |
| 窄窗入口/通知 | 聊天/创作各一个入口，无横向溢出；可见通知底部 643，输入顶部约 727，未遮挡 | 本轮实测 800×900 和桌面 1280×720 |
| 下载 | 点击“下载示例 SVG”动作可触发 | 未读取下载落盘文件，不能声明原图保存/hash 验收通过 |

最终补测：核实失败后其他任务保持 0 提交，刷新仍暂停；明确逐项继续后只执行选定项。未归档源图恢复后标“附件无法恢复 · 禁止提交”，只有取消入口，提交数仍为 0。最终用途切换后 include=false，焦点保持在 reference-role 且 details 保持展开。最终 800×900 的继续队列总入口和逐项继续/取消无重叠，手动继续完成 2 张示意结果。记录见 [browser-evidence.json](browser-evidence.json)。浏览器证据只读取可见页面与 DOM，不访问实际账号或服务。
