# 证据来源与时点

本目录混合保存用户原始材料、旧版证据和 R4 Final 本轮记录，不能因进入最终包就把历史记录算作本轮重测。

- 用户材料：三份中文复审/验收文档、`R3_新增聚合状态反例.json`、`schema反例.json`。文件内容属于审查资料，不替代用户授权。
- 历史：`r2-*`、`r3-*`、`r4-verification.md`、`r4-delivery.json`、`r4-original-counterexamples-result.json`、`summary-drift-validation.json` 及旧反例来源记录；沿用保留。`r4-original-counterexamples-result.json` 的三项反例本轮也由 validator 覆盖，但该文件本身未冒充新日志。
- 本轮：`r4-baseline.json`、`r4-final-contract-audit.md`、`browser-console.json`、`plain-guidance-observation.txt`、`download-link-payload.svg`、刷新后的 `html-static-validation.json` 和 `final-integrity.json`。

本轮校验的完整标准输出在根目录 `schema-validation.log`；浏览器观察汇总在 `browser-evidence.json`，验证范围见 `VERIFICATION.md`。下载 SVG 是从可见链接提取的内容，不是浏览器下载落盘回执。
