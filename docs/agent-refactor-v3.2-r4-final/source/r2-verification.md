## 1. 静态合同与源码核验

- `python validate_registry.py`：36 项 canonical 工具、63 个 JSON Schema 正反样例通过。检查 Draft 2020-12 结构、必填字段、额外字段拒绝、目录与职责一致、目标引用 pair、输入用途条件、逐图 seed、cancel 分支、读不到记录时的最小结果、原子输入撤销与本地链接。
- 独立审查发现并修正：非完成 outputIndex 自相矛盾、emotion 缺少必要值、固定/随机 seed 与逐图结果不闭合、清源回执不能表达蒙版依赖、not_found 强制成功正文。主控复核进一步补齐 referencePurpose 的读取/预览/撤销和取消不存在任务的真实结果。
- HTML 内联 JavaScript 语法检查通过；没有真实模型/图像服务请求代码。静态 ID 无重复。静态检查不证明所有交互分支均可用。
- 固定 HEAD 为 `dfd7caa63ae19bd40651e00127a71efe57b71b4e`。源码只读结论在 MIGRATION_REVIEW；本轮未跑产品构建或产品测试。
- 旧 `agent-refactor-v3.2/SHA256SUMS.txt` 中 19 个文件逐一复算均匹配。保留旧交付；本轮新增文件在独立 r2 目录及新压缩包。

## 4. 明确未验证或未实现

- HTML 的自由语言理解仍为固定演示，只有明确列出的短语；“把参考改为某用途”的自由语言工具调用仅在设计合同中，原型通过用途控件演示。它不是接入 Pi 的真实 Agent。
- HTML 不支持蒙版；源图与依赖蒙版的原子清理、持久撤销由 schema 示例表达，必须在真实 host 验收。
- HTML 刷新重置，未实现持久化重启恢复。D17 的“继续队列”、取消/dispatch 竞态、付费失败 gate、幂等原子提交和崩溃恢复均未做真实实现测试。
- 未验证供应商 schema 投影、真实模型是否遵循提示词、远端取消、实际费用、真实生成 seed/PNG 元数据解析和原始附件下载字节一致性。
- 横图、竖图、多图使用本地 SVG；未以真实服务图片证明通道支持、图像质量或模型视觉点评。
- 未以截图或 schema 通过结论替代 Windows 安装包、DPI/多显示器、键盘完整可访问性或生产端端到端验收。

这些限制是证据边界，后续实施应按 ACCEPTANCE_MATRIX 补齐，不应将本轮材料标为产品验收通过。
