# Agent 多供应商与启动屏修正

日期：2026-10-15。当前实现位于 `desktop/`，本批接续 Agent 执行与 Skill 第一版。

## 使用方式

- 总设置中新增「智能体模型」，与反推、提示词转换模型设置相邻。Agent 左下角的设置入口保留，两处使用同一个编辑器。
- 新增供应商后可分别保存名称、地址、协议、密钥和多个模型。模型可从服务读取，也可手动添加；每个模型独立记录上下文窗口、最大输出、视觉能力和推理强度。
- 输入框旁的模型按钮直接展开供应商 / 模型两列菜单，点击模型即切换；支持方向键、Enter、Escape 和点击外部关闭。「管理模型」才打开设置窗口。
- 上下文窗口编辑期间保留输入草稿，可以先清空再输入。失焦或 Enter 后提交有效数字；上下文范围 8,192–2,000,000，最大输出随上下文上限约束。
- 真正的应用启动屏已接入手机预设原图，采用绘世近黑暖金 / 浅色蓝主题。移除旧芙宁娜 `splash.png` 及旧渐变动画样式；欢迎引导继续使用同一张图。

上一批“已替换启动图”的结论范围不准确：当时仅修改了欢迎引导，实际开机加载屏仍引用独立的 `splash.png`。本批修正真实 `App → StartupScreen` 路径，首次绘制前恢复主题，避免先出现白色背景再切换深色。

## 存储与兼容

`agentProviders` 保存版本号、当前供应商 ID 和供应商列表。供应商以稳定 ID 区分，因此同一个地址或同名模型可以属于不同配置。一次保存 / 切换通过单次 IPC 原子写入注册表，再将所选供应商投影到既有 Agent 运行层字段；未改写当前 Pi 执行链。

旧单供应商配置自动迁入，保留当前凭据和模型参数。旧模型列表中其他可识别端点的模型归入独立供应商，但不复制当前服务密钥；未知协议数据归档保留。已有 flat setter 与直接 `writeStore` 调用只同步实际修改的参数，不以旧模型条目覆盖新输入。

每个供应商密钥分别使用既有系统凭据保护，落盘前独立加密。凭据解密失败时保留密文，不以空值覆盖；锁定配置不能被删除。普通配置备份不包含供应商注册表，只有明确选择 API 配置导出时才纳入。
