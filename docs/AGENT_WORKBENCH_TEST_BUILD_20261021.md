# Agent 工作台与预设测试版（2026-10-21）

本轮基于 `feat/agent-r4-refactor`，让 Agent 使用生成页的实际工作台。生成页与助手页共用参数、提示词、角色提示词、画布和结果；助手的会话与资源以抽屉展开，移除独立右侧“创作”区域和 Agent 角色卡入口。Generate 多角色提示词继续保留。

## 工作台行为

- `read_generation_state` 读取当前工作台安全摘要，`write_workbench_prompts` 按版本写入实际提示词和完整角色提示词数组。手工修改造成版本冲突时拒绝覆盖。
- `prepare_generation({})` 读取当下工作台，冻结模型、模式、提示词、参数、来源、蒙版、参考图、角色项和张数；确认期间工作台发生变化时拒绝使用旧准备。获授权入队的图像任务保持其快照。
- 文字消息排队时冻结原始指令、对话模型与助手预设。轮到该消息执行时重新读取工作台，因此连续修改以此前已应用的结果为基础。
- 保持原生工具协议、费用确认、串行执行、取消、失败/未知不自动重试及回执归属；实际生成结果回填画布时不覆盖随后手工修改的参数。
- 已有文生图、图生图和旧版局部重绘接入此桥。新版手机重绘及增强模式中尚未接入的助手操作明确返回不支持，手工界面继续可用。

## Agent 预设

新增“NovelAI 提示词助手”作为新会话默认预设，依据用户本轮提供文本适配实际工具名、参数与 PC 能力。保留 tag 语法、示例、负向词表及输出约定。原有三个内置预设正文保持不变，继续可选。

资源面板支持直接新建与编辑预设，保存正文、哈希和修订记录；编辑使用版本冲突保护。移除导入入口与角色卡管理入口，保留已有磁盘数据和历史会话。现有会话、用户编辑过的预设以及显式停用设置不会被新默认覆盖；未改动的旧工厂新会话默认迁移到新预设。

本轮仅调整 Agent 默认预设、Agent 基础指令与其工具/Skill 适配。转换、反推及其它功能的提示词模板未修改，留待另行讨论。

修正深色主题下旧重绘来源、引擎以及放大/增强倍率按钮的选中颜色，并补充可访问的选中状态。
